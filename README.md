Sum up the world's news of Tuesday 17 November 2026 in one image. A pure-standard-library Python program draws a newspaper front page — "The World Today" — covering the day's biggest verified stories: Ukraine's strike on the Crimean Bridge (a road span falls into the sea), tankers hit by mines off the Strait of Hormuz as a third US carrier arrives, Trump in Manila with a Xi–Trump–Putin summit set for Thursday in Shenzhen, the JPMorgan software bug that halted banking and Zelle, and five EU states planning a Rwanda return hub — plus a Gaza ceasefire warning and an "Also today" strip (Deutsche Bank leak, Nvidia earnings, the Vulcan rocket failure, COP31, Japan scrambling jets). No network, no randomness: two runs write byte-identical PNGs.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024x1024, under 1 MiB). Without `MAKEFUN_OUTPUT_DIR` it writes to `/output/entry.png`, as the grader does.
